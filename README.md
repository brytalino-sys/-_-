# Калькулятор купажа растительных масел

Веб-приложение для расчёта и оптимизации рецептур купажированных растительных масел.
Работает целиком в браузере, сервер не нужен.

Автор: Титов Е. Д.

## Возможности

- Справочник из 22 пищевых растительных масел: подсолнечное (в т. ч. высокоолеиновое), рапсовое, соевое,
  кукурузное, оливковое, горчичное, хлопковое, арахисовое, кунжутное, сафлоровое, виноградных косточек,
  пальмовое, пальмовый олеин, пальмоядровое, кокосовое, льняное, рыжиковое, семян чиа, конопляное,
  грецкого ореха, рисовых отрубей.
- Ручной расчёт: выбор масел и долей, жирнокислотный состав купажа.
- Оптимизация (симплекс-метод): минимум окисляемости COX, стоимости или индекса атерогенности AI
  при заданном соотношении ω-6 : ω-3 и границах долей; дополнительные ограничения по НЖК, ω-3,
  ПНЖК/НЖК, эруковой кислоте и AI.
- Показатели: НЖК, МНЖК, ПНЖК, ω-6 : ω-3, ПНЖК/НЖК, AI, TI, h/H, COX, расчётное йодное число, стоимость.
- Редактирование справочника и добавление своих масел (данные своей ГЖХ); изменения хранятся в браузере.
- Выгрузка в Excel: листы «Рецептура», «Масла», «ЖК_состав», «Показатели» (с формулами) и «Параметры».

## Развёртывание на GitHub Pages

1. Создайте публичный репозиторий, например `oil-blend-calculator`.
2. Загрузите в корень файлы `index.html` и `README.md` (Add file → Upload files).
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение откроется по адресу `https://<логин>.github.io/oil-blend-calculator/`.

Библиотеки подключаются с CDN: javascript-lp-solver 0.4.24 (jsDelivr) и SheetJS 0.18.5 (cdnjs).

## Источники данных

- Codex Stan 210-1999 (Named Vegetable Oils), табл. 1, и Codex Stan 33-1981 (оливковое масло):
  середины диапазонов, нормированные к 100 %.
- Льняное: OCL, 2016, 23(5), табл. 3. Рыжиковое: Scientific Papers. Series A. Agronomy, 2021, 64(1).
- Семян чиа: Панова А. С., Дергачёв Д. С., Суботялов М. А. Растительные ресурсы, 2020, 56(4), с. 351–362.
- Конопляное: OCL, 2023, 30, ocl230024, табл. 5. Грецкого ореха: Rabrenovic B. et al. Czech J. Food Sci., 2011, 29(1), 74–78.
- Рисовых отрубей: OCL, 2021, 28, ocl210058, табл. 1.
- Индексы AI и TI: Ulbricht T. L. V., Southgate D. A. T. The Lancet, 1991, 338, 985–992.
- COX: Fatemi S. H., Hammond E. G. Lipids, 1980, 15, 379–385. Йодное число: AOCS Cd 1c-85, ISO 3961:2024.
- Ориентир ω-6 : ω-3 = 5–10 : 1: МР 2.3.1.0253-21.
