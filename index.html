Методика расчёта

Содержание жирной кислоты j в купаже – взвешенная сумма по маслам-компонентам: Fj = Σ xi·aij, где xi – массовая доля масла, aij – содержание кислоты в масле, % от суммы ЖК.

При оптимизации условие ω-6 : ω-3 = R приводится к линейному виду Σ xi(ω6i − R·ω3i) = 0, поэтому задача решается симплекс-методом (библиотека javascript-lp-solver). Минимум AI ищется бисекцией по уровню индекса.

AI = (C12:0 + 4·C14:0 + C16:0) / (Σω-3 + Σω-6 + ΣМНЖК)
TI = (C14:0 + C16:0 + C18:0) / (0,5·ΣМНЖК + 0,5·Σω-6 + 3·Σω-3 + Σω-3/Σω-6)
h/H = (C18:1 + C18:2 + C18:3 n-3) / (C12:0 + C14:0 + C16:0)
COX = (C18:1 + 10,3·C18:2 + 21,6·C18:3) / 100
IV = 0,95·C16:1 + 0,86·C18:1 + 1,732·C18:2 + 2,616·C18:3

γ-линоленовая кислота (C18:3 n-6) учитывается в COX и йодном числе как C18:3. Ориентир ω-6 : ω-3 = 5–10 : 1 – по МР 2.3.1.0253-21 (норма для рациона).
