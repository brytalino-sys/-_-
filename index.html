Методика расчёта

Содержание жирной кислоты j в купаже – взвешенная сумма по маслам-компонентам: Fj = Σ xi·aij, где xi – массовая доля масла, aij – содержание кислоты, % от суммы ЖК. Так же, по массе, складываются токоферолы.

Задача оптимизации решается симплекс-методом (javascript-lp-solver). Отношения (ω-6 : ω-3, AI, h/H, ПНЖК/НЖК) в ограничениях линеаризуются: R ≤ r превращается в Σ xi(числительi − r·знаменательi) ≤ 0. Минимум или максимум отношения ищется бисекцией по уровню r, приближение к значению – минимизацией отклонений d⁺ + d⁻. Число масел задаётся бинарными переменными yi: xi ≤ ximax·yi, xi ≥ xmin·yi, nmin ≤ Σ yi ≤ nmax (метод ветвей и границ).

AI = (C12:0 + 4·C14:0 + C16:0) / (Σω-3 + Σω-6 + ΣМНЖК)
TI = (C14:0 + C16:0 + C18:0) / (0,5·ΣМНЖК + 0,5·Σω-6 + 3·Σω-3 + Σω-3/Σω-6)
h/H = (C18:1 + C18:2 + C18:3 n-3) / (C12:0 + C14:0 + C16:0)
COX = (C18:1 + 10,3·C18:2 + 21,6·C18:3) / 100
IV = 0,95·C16:1 + 0,86·C18:1 + 1,732·C18:2 + 2,616·C18:3
Витамин Е, мг α-ТЭ = α-T + 0,5·β-T + 0,1·γ-T + 0,03·δ-T + 0,3·α-T3 + 0,05·β-T3 + 0,01·γ-T3

γ-линоленовая кислота (C18:3 n-6) учитывается в COX и йодном числе как C18:3. TI содержит нелинейное слагаемое Σω-3/Σω-6, поэтому рассчитывается, но не используется как цель. Ориентир ω-6 : ω-3 = 5–10 : 1 – по МР 2.3.1.0253-21 (норма для рациона). Данные по токоферолам часто получены для нерафинированных масел; рафинация снижает их содержание.
